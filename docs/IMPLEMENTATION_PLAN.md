# Implementation plan

## Phase 1 — Foundation
- Confirm routes and responsive layout.
- Connect Supabase.
- Implement trusted profile provisioning and role checks.
- Review RLS policies.

## Phase 2 — Appointments
- Doctors, departments, schedules, slots.
- Transaction-safe booking.
- Queue sessions and tokens.
- Live patient queue.

## Phase 3 — Clinical records
- Consultations and clinical notes.
- Prescriptions and signing.
- Test orders and report uploads.
- Private file storage and access logs.

## Phase 4 — Operations
- OPD/IPD admissions.
- Ward/bed management.
- Nursing observations and medication administration.
- Discharge summaries.

## Phase 5 — Finance and communications
- Invoices and receipts.
- Payment gateway and verified webhooks.
- Insurance claims.
- WhatsApp/SMS provider integration and delivery logs.

## Phase 6 — Launch readiness
- Security review and tests.
- Accessibility and localization review.
- Backups and recovery drills.
- Privacy notice, consent flows, retention policy, and incident response.
